How it works

      
    
        
  1. Code picks the lines. A rules page can run to 40,000 characters. Code keeps the lines that contain a date, plus the short label above each one, so the model reads a few hundred characters instead of the whole page.
    2. 
        
  2. Gemma points. Gemma 4 E2B, running on your GPU through WebLLM, lists each event and copies the date, the time and the zone exactly as written. Its answer is held to a grammar, so it always parses.
    3. 
        
  3. Code checks. Every quote is looked up on the page. A date Gemma reworded or made up is thrown out and listed.
    4. 
        
  4. Code converts. The date and time are read by plain functions, and Luxon applies the time zone database: daylight saving on that exact date, "PST" written in summer, Anywhere on Earth, missing years.
    5. 
        
  5. You get a calendar. One .ics file for every event, with reminders 3 days and 3 hours before each deadline, or one Google Calendar link per row.
    6. 
      

      
The recorded runs are real outputs from Gemma 4 E2B on pages from contests I entered, saved during my test. The checker and the time zone code run live on them in your browser. Live mode needs Chrome or Edge with WebGPU and downloads about 2.8 GB once.
